# 조은지 | 프로젝트와 경험

데이터분석 공모전, 학습 앱 개발, 해커톤에서 직접 맡은 작업과 결과물을 정리합니다.

## 자료 구성

- **광진구 공모전:** 경험 설명, 보고서 원본, 보고서에서 발췌한 분석·지도 이미지
- **ssen-voca:** 개인 담당 작업, 진행 중인 설계 고민, 앱·서버 저장소 링크
- **Wonnie:** 개인 기여와 문제 해결 과정, 데모·Figma 화면, 캐릭터·기획 이미지

각 폴더의 README에서 해당 경험을 읽고 관련 자료를 열 수 있습니다. 코드가 없는 경험도 문서와 이미지로 정리합니다.
